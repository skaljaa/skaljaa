## 🚀 About Me

I'm a **senior Computer Science student** (IUS, graduating 2027) working on agentic AI systems and backend engineering. I build production-grade Python backends with **FastAPI**, **PostgreSQL**, and **Celery**, and I spend most of my time thinking about how to wire LLMs into real systems — through **tool-calling**, **RAG pipelines**, and **MCP-style architectures**.

Most recently at **Bloomteq**, building **BloomHub** — an agent-first HR platform where an LLM autonomously orchestrates multi-step workflows through structured tool-use, backed by a pgvector RAG pipeline and a JWT-secured FastAPI backend with RBAC and rate limiting. Also shipped voice-driven input via Whisper behind a swappable provider abstraction, and worked against live AWS infrastructure (S3, ECS, CloudFront).

Before that: a 30-table, 316-test capstone platform with async ML serving on Celery + Redis, Python automation work at FabLab, and a semester as a Calculus 1 teaching assistant.
